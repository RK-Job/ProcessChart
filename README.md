# 1ヶ月工程表 Webアプリケーション

フレームワーク非依存（バニラ HTML / CSS / JavaScript）で動作する、ドラッグ＆ドロップ操作のガントチャート型工程表アプリです。サーバー不要・`file://` で直接開いても動作します。

## 使い方

1. `index.html` をブラウザ（Chrome / Edge 最新版）で開く。
2. 対象期間（開始日〜終了日）・工事名称・担当者・会社名を入力する。複数月にまたがる期間も指定でき、月が変わる箇所は見出しに月ラベルが表示される。
3. ガントチャートエリアのセルを右クリックすると工程追加ダイアログが開く。工程名・開始日・終了日・色を入力してOKで工程バーを作成する。
   - 作成済みのバー中央をドラッグ: 移動
   - バー両端をドラッグ: 期間の伸縮（1日単位でスナップ）
   - バーをダブルクリック、または右クリック: 工程名・日程・色の変更、削除
4. 「＋ 行追加」で作業項目行を追加。行の ✕ で削除、ドラッグで並び替え。
   - 行の ▼ ボタンから「子項目にする」「インデントを解除」「上へ移動」「下へ移動」を選択できる。子項目は最大4階層まで。
   - 子項目を持つ行には ▾ / ▸ の折りたたみボタンが表示され、クリックで子項目の表示・非表示を切り替えられる（折りたたみ中の行は印刷・PDF出力にも含まれない）。
   - 子項目のある行を削除すると、その子項目もまとめて削除される。
5. 「JSON保存」で現在の内容をJSONファイルとしてダウンロード。「JSONを開く」（またはファイルのドラッグ＆ドロップ）で再読み込み。
6. 「印刷 / PDF出力」でA4横のレイアウトに整形して印刷・PDF保存。

編集内容はブラウザの LocalStorage に自動的に一時保存され、再訪問時に復元されます。

## ファイル構成

```
index.html      画面構造
css/style.css   スタイル（印刷用レイアウトを含む）
js/holidays.js  日本の祝日計算（振替休日・国民の休日を含む近似計算）
js/app.js       アプリ本体のロジック
```

## データ形式

`meta` / `project` / `rows[].bars[]` の構造でJSONファイルを保存・読み込みします。

- `project.start_date` / `project.end_date`: 対象期間の開始日・終了日（`YYYY-MM-DD`）
- `rows[].level`: 作業項目の階層レベル（0が最上位、最大4）
- `rows[].collapsed`: 子項目を折りたたみ表示中かどうか
- `rows[].bars[].start_date` / `end_date`: 工程バーの開始日・終了日（`YYYY-MM-DD`）

対象期間は最大366日まで指定可能です。
